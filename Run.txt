2. Tao .env tu .env.example, dien API key, 4 model, APP_ORIGINS HTTPS va mat khau admin khoi tao.
3. docker compose up -d --build
4. docker compose logs --tail=100 app
5. Cau hinh Nginx/TLS theo deploy/nginx.conf.example.

Khoi dong lai: docker compose restart app
Khong dung docker compose down -v: lenh nay xoa volume du lieu.
